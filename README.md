# 提出課題 ネットワークベクトル計算機

下記の仕様を満たすサーバプログラムとクライアントプログラムをPython 3で実装し、動作を確認したうえで、サーバとクライアントのソースコードをGitHubに提出してください。ファイル名は指定されたものにしてください。提出版は main ブランチに置き、`submit` タグを付けてください。再提出の際は、`submit1`、`submit2`、... のように、`submit` の後に数字を付けたタグにしてください。

## 仕様

### サーバ vcalc_server.py

適切なポート番号（例えば50003）で動作し、TCPによる通信でクライアントから`値1a 値1b 演算子 値2a 値2b`という形式の文字列を受け取り、`演算結果a 演算結果b`という形式の文字列を返送します。演算結果aと演算結果bは、それぞれ（値1a 指定された演算 値2a）、（値1b 指定された演算 値2b）です。つまり、ネットワーク経由で使うベクトル計算機です。

使用できる演算子は、`+`、`-`、`*`、`/`の4つです。

演算結果は`f'{a:g} {b:g}'`のように`:g`書式で整形して返送してください（例: `31.93 128`）。

不正な入力（ゼロ除算、未知の演算子、項目数の過不足、数値として解釈できない値）を受け取った場合は、`ERROR <理由>`という形式の文字列（例: `ERROR division by zero`）を返送してください。このときもサーバは終了せず、引き続き新たなクライアントからの接続を待ち続けてください。

1回の接続で行う計算は1回です。送受信するメッセージは短いので、`recv()`は1回呼び出して受け取れば十分です。ただし、TCPはメッセージの区切りを保存しないバイトストリームであり、本来は1回の`recv()`でデータがすべて届く保証はないことに注意してください。

サーバは、一つのクライアントとの通信を終えたら、その通信に使ったソケットは閉じますが、待ち受け用のソケットは閉じずに、新たなクライアントからの接続を待ち続けるようにしてください。これは特別なことではなく、サンプルにも示しているとおり、サーバとしてごく普通の実装です。

### クライアント vcalc_client.py

コマンドラインで指定されたホストとポート番号で動作するサーバプログラムにTCPで接続し、コマンドラインで指定された計算式（例: `'10.3 32 * 3.1 4'`）の文字列をサーバに送信します。そして、サーバから計算結果を含む応答を受信し、その結果を画面に表示します。サーバから`ERROR`で始まる応答を受け取った場合も、そのまま表示してください。

以下に実行例を示します。計算式の部分は必ずシングルクォーテーションで囲んでください（`'式...'`）。Pythonスクリプトから見た`sys.argv`の要素数は4個（つまり`len(sys.argv) == 4`）になります。また、クライアントは計算式である`sys.argv[3]`をそのまま`encode()`でバイト列（bytes）に変換して、サーバに送ってください。

```
$ python3 vcalc_client.py localhost 50003 '10.3 32 * 3.1 4'
31.93 128
$ 
```

### ヒント

- 文字列の分解には、文字列（`str`）のメソッド`split()`が使えます。空白文字（スペース、タブ、改行）で区切られた文字列を分解し、リストにして返します。

```
>>> phrase = 'What a new world'
>>> words = phrase.split()
>>> words
['What', 'a', 'new', 'world']
>>>
```

- ネットワークに文字列データを送る前には、必ず文字列を`encode()`でバイト列（bytes）に変換してから送信してください。

- ネットワークから受け取ったデータを文字列として扱う前には、必ず受け取ったバイト列に対して`decode()`を行ってください。つまり`received_string = received_bytes.decode()`のようにします。

## おまけ

コマンドラインから受け取った文字列をもとに足し算をするだけのサンプルプログラムです。通信は行いません。
（サンプルプログラムに出てくる英語が分からないときは、ちゃんと辞書を引きましょう。例えば[Weblio](https://ejje.weblio.jp)があります。）

```python
# simple_txt_parser.py

import sys

if len(sys.argv) < 2:
    sys.exit(f"Usage: {sys.argv[0]} 'number number'")

print(f'sys.argv[1]: {sys.argv[1]}')

tokens = sys.argv[1].split()
for i, token in enumerate(tokens):
    print(f'tokens[{i}]: {token}')

# add two numbers
s = float(tokens[0]) + float(tokens[1])
print(f'{float(tokens[0])} + {float(tokens[1])} = {s}')
```
